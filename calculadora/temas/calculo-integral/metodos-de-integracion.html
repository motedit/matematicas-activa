Métodos de integración: ejercicios resueltos paso a paso

Despejamos una incógnita en una ecuación y la reemplazamos en la otra: queda una ecuación con una sola incógnita. Acá tenés 7 ejemplos resueltos, con cada paso explicado y verificado.

Conceptos clave

Método de sustitución

Despejamos una incógnita en una ecuación y la reemplazamos en la otra: queda una ecuación con una sola incógnita.

y=7−2x⇒x−(7−2x)=2

Sustitución en integrales

Es la regla de la cadena al revés: si aparece una función y su derivada, la llamamos u y la integral se simplifica.

∫2xcos(x2)dx=∫cosudu

Primitivas

Integrar es lo contrario de derivar. Como la derivada de una constante es 0, todas las primitivas difieren en una constante C.

∫2xdx=x2+C

Logaritmos

El logaritmo responde: ¿a qué exponente hay que elevar la base para obtener el número? Sus propiedades convierten productos en sumas y potencias en productos.

logb​(xy)=logb​x+logb​y,logb​xn=nlogb​x

Fracciones

Una fracción indica una división: el denominador dice en cuántas partes iguales se divide y el numerador, cuántas se toman.

43​=3:4=0,75

Diferenciales binomias

Chebyshev demostró que ∫ xᵐ(a + bxⁿ)ᵖ dx tiene primitiva elemental solo en tres casos; en cada uno hay un cambio de variable que la convierte en un polinomio.

nm+1​∈Z⇒u=a+bxn

Ejemplos resueltos

Ejemplo 1: ∫ x e^x dx por partes

Método: Integración por partes

  1. 1

    Escribimos la integral

    Buscamos una función F(x) cuya derivada sea el integrando: F'(x) = f(x). Esa F se llama antiderivada o primitiva.

    ∫x⋅exdx
  2. 2

    Integramos por partes

    ∫udv=uv−∫vdu. Elegimos u con la regla ILATE (Logarítmicas, Inversas trigonométricas, Algebraicas, Trigonométricas, Exponenciales): la que aparece primero es u.

    u=x⇒du=1dx
    dv=exdx⇒v=ex
    ∫x⋅exdx=x⋅ex−∫exdx
  3. 3

    Escribimos el resultado

    La antiderivada no es única: si F sirve, también sirve F + C para cualquier constante C (porque la derivada de una constante es 0).

    ∫x⋅exdx=x⋅ex−ex+C
  4. 4

    Verificamos

    Derivamos el resultado: tiene que dar la función que integramos (la derivada de C es 0).

    dxd​[x⋅ex−ex+C]=x⋅ex
    x=0,37:0,535662=0,535662,x=0,81:1,820805=1,820805✓

Resultado

∫x⋅exdx=x⋅ex−ex+C

Ejemplo 2: ∫ e^x sen x dx

Método: Integración por partes

  1. 1

    Escribimos la integral

    Buscamos una función F(x) cuya derivada sea el integrando: F'(x) = f(x). Esa F se llama antiderivada o primitiva.

    ∫ex⋅senxdx
  2. 2

    Integramos por partes

    ∫udv=uv−∫vdu. Elegimos u con la regla ILATE (Logarítmicas, Inversas trigonométricas, Algebraicas, Trigonométricas, Exponenciales): la que aparece primero es u.

    u=senx⇒du=cosxdx
    dv=exdx⇒v=ex
    ∫ex⋅senxdx=ex⋅senx−∫ex⋅cosxdx
  3. 3

    Aplicamos partes otra vez

    ∫udv=uv−∫vdu. Elegimos u con la regla ILATE (Logarítmicas, Inversas trigonométricas, Algebraicas, Trigonométricas, Exponenciales): la que aparece primero es u.

    u=cosx⇒du=−senxdx
    dv=exdx⇒v=ex
    ∫ex⋅cosxdx=ex⋅cosx−∫−ex⋅senxdx
  4. 4

    Volvió a aparecer la integral original

    Es una integral “cíclica”: la llamamos I, la pasamos al otro miembro y despejamos.

    I=ex⋅senx−ex⋅cosx−I;Rightarrow;I=21​(ex⋅senx−ex⋅cosx)
  5. 5

    Escribimos el resultado

    La antiderivada no es única: si F sirve, también sirve F + C para cualquier constante C (porque la derivada de una constante es 0).

    ∫ex⋅senxdx=21​ex⋅senx−21​ex⋅cosx+C
  6. 6

    Verificamos

    Derivamos el resultado: tiene que dar la función que integramos (la derivada de C es 0).

    dxd​[21​ex⋅senx−21​ex⋅cosx+C]=21​(ex⋅senx+ex⋅cosx)−21​(ex⋅cosx−ex⋅senx)
    x=0,37:0,523523=0,523523,x=0,81:1,628131=1,628131✓

Resultado

∫ex⋅senxdx=21​ex⋅senx−21​ex⋅cosx+C

Ejemplo 3: ∫ (x + 5)/(x^2 + x - 2) dx

Método: Fracciones parciales

  1. 1

    Escribimos la integral

    Buscamos una función F(x) cuya derivada sea el integrando: F'(x) = f(x). Esa F se llama antiderivada o primitiva.

    ∫x2+x−2x+5​dx
  2. 2

    Factorizamos el denominador

    Escribimos el denominador como producto de factores lineales (x − r) y cuadráticos sin raíces reales.

    x2+x−2=1(x−1)(x+2)
  3. 3

    Planteamos las fracciones parciales

    A cada factor lineal le corresponde A/(x − r) (y una fracción por cada potencia si se repite); a cada cuadrático, (Bx + C)/(x² + px + q). Igualamos numeradores y resolvemos el sistema de los coeficientes.

    x2+x−2x+5​=x−12​−x+21​
    A1​=2,A2​=−1
  4. 4

    Integramos cada fracción

    Las lineales dan logaritmos (o potencias si están repetidas); las cuadráticas dan un logaritmo más un arco tangente (completando cuadrados).

    ∫x−12​dx=2ln∣x−1∣
    ∫−x+21​dx=−ln∣x+2∣
  5. 5

    Escribimos el resultado

    La antiderivada no es única: si F sirve, también sirve F + C para cualquier constante C (porque la derivada de una constante es 0).

    ∫x2+x−2x+5​dx=2ln∣x−1∣−ln∣x+2∣+C
  6. 6

    Verificamos

    Derivamos el resultado: tiene que dar la función que integramos (la derivada de C es 0).

    dxd​[2ln∣x−1∣−ln∣x+2∣+C]=(∣x−1∣)22x−2​+(∣x+2∣)2−x−2​
    x=0,37:−3,596544=−3,596544,x=0,81:−10,882188=−10,882188✓

Resultado

∫x2+x−2x+5​dx=2ln∣x−1∣−ln∣x+2∣+C

Ejemplo 5: ∫ √(4 - x^2) dx

Método: Sustitución trigonométrica

  1. 1

    Escribimos la integral

    Buscamos una función F(x) cuya derivada sea el integrando: F'(x) = f(x). Esa F se llama antiderivada o primitiva.

    ∫−x2+4​dx
  2. 2

    Elegimos la sustitución trigonométrica

    La raíz tiene la forma de un lado de un triángulo rectángulo. Usamos x = a·sen θ (para √(a² − x²)), así la raíz se simplifica con una identidad pitagórica.

    x=2senθ,dx=2cosθdθ
    −x2+4​=2cosθ
  3. 3

    Integramos en θ

    Reemplazamos todo y queda una integral trigonométrica.

    ∫4cos2θdθ=4(21​θ+41​sen(2θ))
  4. 4

    Volvemos a x con el triángulo

    Dibujamos el triángulo rectángulo de la sustitución y leemos cada razón en función de x.

    θ=arcsen(21​x)
    senθ=21​x
    ⇒4(21​arcsen(21​x)+81​x⋅−x2+4​)
  5. 5

    Escribimos el resultado

    La antiderivada no es única: si F sirve, también sirve F + C para cualquier constante C (porque la derivada de una constante es 0).

    ∫−x2+4​dx=2arcsen(21​x)+21​x⋅−x2+4​+C
  6. 6

    Verificamos

    Derivamos el resultado: tiene que dar la función que integramos (la derivada de C es 0).

    dxd​[2arcsen(21​x)+21​x⋅−x2+4​+C]=−41​x2+1​1​+21​(−x2+4​−−x2+4​x2​)
    x=0,37:1,965477=1,965477,x=0,81:1,828633=1,828633✓

Resultado

∫−x2+4​dx=2arcsen(21​x)+21​x⋅−x2+4​+C

Ejemplo 6: ∫ x cos(x^2) dx

  2. 2

    Hacemos un cambio de variable

    u=x2⇒du=2xdx
    ∫x⋅cos(x2)dx=∫21​cosudu=21​senu
    volvemos a x:21​sen(x2)
  3. 3

    dxd​[21​sen(x2)+C]=x⋅cos(x2)
    x=0,37:0,366538=0,366538,x=0,81:0,641826=0,641826✓

Ejemplo 7: ∫ x^3√(1 + x^2) dx por diferencial binomia

Método: Diferencial binomia

  1. 1

    Escribimos la integral

    Buscamos una función F(x) cuya derivada sea el integrando: F'(x) = f(x). Esa F se llama antiderivada o primitiva.

    ∫x3⋅x2+1​dx
  2. 2

    Reconocemos una diferencial binomia

    Es de la forma ∫xm(a+bxn)pdx. Por el teorema de Chebyshev se puede integrar si p, (m+1)/n o (m+1)/n + p es entero.

    m=3,n=2,p=21​,a=1,b=1
    nm+1​=2,nm+1​+p=25​
  3. 3

    Caso (m + 1)/n entero

    Hacemos el cambio u = a + b xⁿ: entonces xⁿ⁻¹dx = du/(n b) y el resto de las x se escribe con u.

    u=x2+1
    ∫21​u​⋅(u−1)du=51​u25​−31​u23​
  4. 4

    Escribimos el resultado

    La antiderivada no es única: si F sirve, también sirve F + C para cualquier constante C (porque la derivada de una constante es 0).

    ∫x3⋅x2+1​dx=51​(x2+1)25​−31​(x2+1)23​+C
  5. 5

    Verificamos

    Derivamos el resultado: tiene que dar la función que integramos (la derivada de C es 0).

    dxd​[51​(x2+1)25​−31​(x2+1)23​+C]=x⋅(x2+1)23​−x⋅x2+1​
    x=0,37:0,054009=0,054009,x=0,81:0,683909=0,683909✓

Resultado

∫x3⋅x2+1​dx=51​(x2+1)25​−31​(x2+1)23​+C
