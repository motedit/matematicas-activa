Contraste de hipótesis: ejercicios resueltos paso a paso

Suponemos H₀ cierta y vemos qué tan raro sería lo observado. Si es muy raro (p < α), dudamos de H₀ y la rechazamos. Acá tenés 5 ejemplos resueltos, con cada paso explicado y verificado.

Conceptos clave

Contraste de hipótesis

Suponemos H₀ cierta y vemos qué tan raro sería lo observado. Si es muy raro (p < α), dudamos de H₀ y la rechazamos.

p<α⇒se rechaza H0​

Inferencia

Con una muestra estimamos lo que pasa en toda la población. Como la muestra varía, se trabaja con distribuciones (normal, t, chi-cuadrado) para medir cuánto confiar.

t=s/n​xˉ−μ0​​

Pendiente

La pendiente mide cuánto sube (o baja) la recta por cada unidad que avanzamos en x: es el cociente entre la variación de y y la de x.

m=x2​−x1​y2​−y1​​

Varianza y desviación

Miden cuánto se alejan los datos de la media. Elevamos al cuadrado para que los desvíos positivos y negativos no se cancelen; la raíz devuelve las unidades originales.

σ=n∑(xi​−xˉ)2​​

Estandarizar

Toda normal se transforma en la normal estándar restando la media y dividiendo por la desviación: z dice a cuántas desviaciones está el valor de la media.

z=σx−μ​

Propiedad distributiva

Multiplicar por una suma es lo mismo que multiplicar por cada término y sumar los resultados. Así “sacamos” los paréntesis.

3(x+2)=3x+6

Ejemplos resueltos

Ejemplo 1: contraste de hipótesis: μ0 = 50, x̄ = 53, s = 6, n = 36, α = 0,05, la media es mayor

Método: Prueba t de Student para la media

  1. 1

    Planteamos las hipótesis

    H₀ es la afirmación que se pone a prueba (lleva el igual); H₁ es lo que queremos ver si los datos apoyan.

    H0​:μ=50
    H1​:μ>50
    α=0,05(probabilidad de error tipo I: rechazar H0​ siendo cierta)
  2. 2

    Calculamos el estadístico t de Student

    σ es desconocida: usamos t con 35 grados de libertad.

    t=s/n​xˉ−μ0​​=6/36​53−(50)​=3
  3. 3

    Calculamos el valor p y decidimos

    El valor p es la probabilidad de obtener un resultado tan extremo como el observado si H₀ fuera cierta. Si p < α (= 0,05), rechazamos H₀.

    p-valor=0,0025<α=0,05⇒se rechaza H0​
    Los datos muestran una diferencia significativa con el valor de H₀.
  4. 4

    Verificamos

    Comparamos también el estadístico con el valor crítico: la decisión tiene que coincidir con la del valor p.

    t=3>1,69⇒zona de rechazo✓

Resultado

t=3,p=0,0025⇒se rechaza H₀

Ejemplo 2: chi cuadrado observadas: 18, 22, 20, 40

Método: Chi-cuadrado de bondad de ajuste

  1. 1

    Planteamos las hipótesis

    Prueba de bondad de ajuste: ¿los datos observados siguen la distribución esperada?

    H0​: los datos se ajustan a la distribucioˊn esperada
    H1​: no se ajustan
  2. 2

    Calculamos el estadístico chi-cuadrado

    Sumamos (observada − esperada)² / esperada en cada casilla.

    χ2=∑E(O−E)2​=25(18−25)2​+25(22−25)2​+25(20−25)2​+25(40−25)2​=12,32
    grados de libertad=3
  3. 3

    Calculamos el valor p y decidimos

    El valor p es la probabilidad de obtener un resultado tan extremo como el observado si H₀ fuera cierta. Si p < α (= 0,05), rechazamos H₀.

    p-valor=0,0064<α=0,05⇒se rechaza H0​
    Hay evidencia de que los datos no siguen la distribucioˊn esperada.
  4. 4

    Verificamos

    Comparamos también el estadístico con el valor crítico: la decisión tiene que coincidir con la del valor p.

    χ2=12,32>7,815⇒zona de rechazo✓

Resultado

χ2=12,32,p=0,0064

Ejemplo 3: chi cuadrado de independencia: Varones: 20, 30; Mujeres: 35, 15

Método: Chi-cuadrado de independencia

  1. 1

    Planteamos las hipótesis

    Prueba de independencia: ¿las dos variables de la tabla están relacionadas?

    H0​: las variables son independientes
    H1​: estaˊn relacionadas
  2. 2

    Calculamos las frecuencias esperadas

    Si fueran independientes, cada casilla esperaría (total de fila × total de columna) / total.

    C1C2
    Varones27,522,5
    Mujeres27,522,5
  3. 3

    Calculamos el estadístico chi-cuadrado

    Sumamos (observada − esperada)² / esperada en cada casilla.

    χ2=∑E(O−E)2​=27,5(20−27,5)2​+22,5(30−22,5)2​+27,5(35−27,5)2​+22,5(15−22,5)2​=9,0909
    grados de libertad=1
  4. 4

    Calculamos el valor p y decidimos

    El valor p es la probabilidad de obtener un resultado tan extremo como el observado si H₀ fuera cierta. Si p < α (= 0,05), rechazamos H₀.

    p-valor=0,0026<α=0,05⇒se rechaza H0​
    Hay evidencia de relacioˊn entre las variables.
  5. 5

    Verificamos

    Comparamos también el estadístico con el valor crítico: la decisión tiene que coincidir con la del valor p.

    χ2=9,091>3,841⇒zona de rechazo✓

Resultado

χ2=9,0909,p=0,0026

Ejemplo 4: prueba t para dos muestras: grupo A: 12, 15, 14, 10, 13; grupo B: 18, 17, 16, 19, 15

Método: Prueba t para dos muestras

  1. 1

    Planteamos las hipótesis

    Comparamos las medias de dos grupos independientes.

    H0​:μ1​=μ2​
    H1​:μ1​=μ2​
  2. 2

    Resumimos cada grupo

    Media y varianza muestral de cada grupo.

    xˉ1​=12,8,s12​=3,7,n1​=5
    xˉ2​=17,s22​=2,5,n2​=5
  3. 3

    Calculamos el estadístico t (Welch)

    No suponemos varianzas iguales: el error estándar combina las dos varianzas.

    t=n1​s12​​+n2​s22​​​xˉ1​−xˉ2​​=1,1136−4,2​=−3,772
    gl≈7,71
  4. 4

    Calculamos el valor p y decidimos

    El valor p es la probabilidad de obtener un resultado tan extremo como el observado si H₀ fuera cierta. Si p < α (= 0,05), rechazamos H₀.

    p-valor=0,0058<α=0,05⇒se rechaza H0​
    Hay diferencia significativa entre las medias de los grupos.
  5. 5

    Verificamos

    Comparamos también el estadístico con el valor crítico: la decisión tiene que coincidir con la del valor p.

    t=−3,772>±2,321⇒zona de rechazo✓

Resultado

t=−3,772,p=0,0058

Ejemplo 5: contraste μ0 = 100, σ = 15, x̄ = 106, n = 25, μ1 = 108, error tipo II

Método: Prueba z para la media

  1. 1

    Planteamos las hipótesis

    H₀ es la afirmación que se pone a prueba (lleva el igual); H₁ es lo que queremos ver si los datos apoyan.

    H0​:μ=100
    H1​:μ=100
    α=0,05(probabilidad de error tipo I: rechazar H0​ siendo cierta)
  2. 2

    Calculamos el estadístico z

    σ es conocida: usamos la normal.

    z=σ/n​xˉ−μ0​​=15/25​106−(100)​=2
  3. 3

    Calculamos el valor p y decidimos

    El valor p es la probabilidad de obtener un resultado tan extremo como el observado si H₀ fuera cierta. Si p < α (= 0,05), rechazamos H₀.

    p-valor=0,0455<α=0,05⇒se rechaza H0​
    Los datos muestran una diferencia significativa con el valor de H₀.
  4. 4

    Verificamos

    Comparamos también el estadístico con el valor crítico: la decisión tiene que coincidir con la del valor p.

    z=2>±1,96⇒zona de rechazo✓
  5. 5

    Calculamos el error tipo II

    β es la probabilidad de NO rechazar H₀ cuando en realidad la media es μ₁. La potencia del test es 1 − β.

    β=P(no rechazar H0​∣μ=108)=0,2399
    potencia=1−β=0,7601

Resultado

z=2,p=0,0455⇒se rechaza H₀
