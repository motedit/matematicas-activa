Estimación de parámetros: ejercicios resueltos paso a paso

Miden cuánto se alejan los datos de la media. Elevamos al cuadrado para que los desvíos positivos y negativos no se cancelen; la raíz devuelve las unidades originales. Acá tenés 3 ejemplos resueltos, con cada paso explicado y verificado.

Conceptos clave

Varianza y desviación

Miden cuánto se alejan los datos de la media. Elevamos al cuadrado para que los desvíos positivos y negativos no se cancelen; la raíz devuelve las unidades originales.

σ=n∑(xi​−xˉ)2​​

Intervalo de confianza

Como la muestra varía, damos un rango: estimación ± margen. Más confianza o menos datos hacen el intervalo más ancho.

xˉ±zn​σ​

Inferencia

Con una muestra estimamos lo que pasa en toda la población. Como la muestra varía, se trabaja con distribuciones (normal, t, chi-cuadrado) para medir cuánto confiar.

t=s/n​xˉ−μ0​​

Sumas de Riemann

El área bajo la curva se aproxima con rectángulos. Cuantos más (y más finitos) usemos, mejor la aproximación; en el límite da exactamente la integral.

∫ab​f=n→∞lim​∑f(xi​)Δx

Proporciones

Dos razones forman una proporción si son iguales. En toda proporción, el producto de los extremos es igual al producto de los medios: con eso se despeja el valor desconocido.

ba​=dc​⟺a⋅d=b⋅c

Área con integrales

Sumamos infinitos rectángulos de altura (arriba − abajo) y ancho dx. Si la curva cruza el eje, separamos los tramos para que no se resten áreas.

A=∫ab​∣f(x)−g(x)∣dx

Ejemplos resueltos

Ejemplo 1: intervalo de confianza del 95% para la media: x̄ = 52, s = 8, n = 25

Método: Intervalo para la media (t de Student)

  1. 1

    Estimación puntual

    Estimamos la media poblacional μ con la media muestral, y la desviación con s.

    xˉ=52
    s=8
    n=25
  2. 2

    Elegimos la t de Student (σ desconocida)

    Como σ es desconocida y la estimamos con s, usamos la t de Student con n − 1 = 24 grados de libertad.

    t24;α/2​=2,064
  3. 3

    Calculamos el margen de error

    Valor crítico por el error estándar de la media (desviación sobre √n).

    E=2,064⋅25​8​=3,3022
  4. 4

    Armamos el intervalo de confianza

    Con un 95 % de confianza, la media poblacional está entre estos valores.

    IC=(xˉ−E;xˉ+E)=(48,6978;55,3022)
  5. 5

    Verificamos

    El área central entre −valor crítico y +valor crítico tiene que ser el nivel de confianza, y el intervalo tiene que estar centrado en x̄.

    P(−2,064<T<2,064)=0,95✓
    248,6978+55,3022​=52✓

Resultado

IC95%​(μ)=(48,6978;55,3022)

Ejemplo 2: intervalo de confianza 90%: n = 200, 84 éxitos, proporción

Método: Intervalo para una proporción

  1. 1

    Estimación puntual

    El mejor valor único para estimar la proporción poblacional es la proporción de la muestra.

    p^​=20084​=0,42
  2. 2

    Buscamos el valor crítico

    Para un nivel de confianza del 90 % buscamos z con área 0,95 a la izquierda.

    zα/2​=1,645
  3. 3

    Calculamos el margen de error

    Usamos el error estándar de la proporción p^​(1−p^​)/n​.

    E=znp^​(1−p^​)​​=1,6452000,42⋅0,58​​=0,0574
  4. 4

    Armamos el intervalo

    Estimación puntual ± margen de error.

    IC90%​=(0,3626;0,4774)
  5. 5

    Verificamos

    El centro del intervalo tiene que ser p̂ y el área entre −z y z tiene que ser el nivel de confianza.

    20,3626+0,4774​=0,42✓
    Φ(1,645)−Φ(−1,645)=0,9✓

Resultado

p^​=0,42,IC=(0,3626;0,4774)

Ejemplo 3: intervalo de confianza del 99% con σ = 5: datos 48, 52, 50, 47, 53, 51, 49, 50

Método: Intervalo para la media (z)

  1. 1

    Estimación puntual

    Estimamos la media poblacional μ con la media muestral, y la desviación con s. Las calculamos con los datos.

    xˉ=50
    s=2
    n=8
  2. 2

    Elegimos la normal (σ conocida)

    Como se conoce la desviación poblacional σ, usamos la distribución normal.

    zα/2​=2,576
  3. 3

    Calculamos el margen de error

    Valor crítico por el error estándar de la media (desviación sobre √n).

    E=2,576⋅8​5​=4,5535
  4. 4

    Armamos el intervalo de confianza

    Con un 99 % de confianza, la media poblacional está entre estos valores.

    IC=(xˉ−E;xˉ+E)=(45,4465;54,5535)
  5. 5

    Verificamos

    El área central entre −valor crítico y +valor crítico tiene que ser el nivel de confianza, y el intervalo tiene que estar centrado en x̄.

    P(−2,576<Z<2,576)=0,99✓
    245,4465+54,5535​=50✓

Resultado

IC99%​(μ)=(45,4465;54,5535)
