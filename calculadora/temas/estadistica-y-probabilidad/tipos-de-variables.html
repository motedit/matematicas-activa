Tipos de variables: ejercicios resueltos paso a paso

Saber el tipo de variable dice qué podemos calcular: con cualitativas solo contamos (moda); con cuantitativas, también promedios y dispersión. Acá tenés 2 ejemplos resueltos, con cada paso explicado y verificado.

Conceptos clave

Tipos de variables

Saber el tipo de variable dice qué podemos calcular: con cualitativas solo contamos (moda); con cuantitativas, también promedios y dispersión.

cuantitativa continua: se mide

Ejemplos resueltos

Ejemplo 1: clasificar: color de ojos, número de hermanos, estatura, nivel de estudios

Método: Clasificación de variables

  1. 1

    Recordamos la clasificación

    Una variable es cualitativa si sus valores son categorías (palabras) y cuantitativa si son números que se pueden contar o medir. Las cualitativas pueden ser nominales (sin orden) u ordinales (con orden); las cuantitativas, discretas (se cuentan: valores aislados) o continuas (se miden: pueden tomar cualquier valor intermedio).

    TipoPregunta claveEjemplo
    Cualitativa nominal¿Son categorías sin orden?color de ojos
    Cualitativa ordinal¿Son categorías que se pueden ordenar?nivel de estudios
    Cuantitativa discreta¿Se cuenta? (0, 1, 2, …)cantidad de hermanos
    Cuantitativa continua¿Se mide? (admite decimales)estatura
  2. 2

    Clasificamos cada variable

    Para cada una nos preguntamos: ¿son palabras o números? Si son palabras, ¿tienen orden? Si son números, ¿se cuentan o se miden?

    VariableTipo¿Por qué?
    color de ojoscualitativa nominalsus valores son categorías sin orden
    número de hermanoscuantitativa discretase obtiene contando: toma valores enteros aislados
    estaturacuantitativa continuase obtiene midiendo: admite valores intermedios
    nivel de estudioscualitativa ordinalsus valores son categorías que se pueden ordenar
  3. 3

    Verificamos

    Revisamos con las preguntas clave: una cuantitativa tiene que tener sentido sumarla o promediarla; una ordinal, ordenarla; una nominal, solo contar cuántas veces aparece cada categoría.

    4 de 4 variables clasificadas✓

Resultado

color de ojos: cualitativa nominal,nuˊmero de hermanos: cuantitativa discreta,estatura: cuantitativa continua,nivel de estudios: cualitativa ordinal
