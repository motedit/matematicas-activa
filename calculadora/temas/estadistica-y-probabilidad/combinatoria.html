Combinatoria: ejercicios resueltos paso a paso

Elegir k de n sin importar el orden: se cuentan las variaciones y se divide por las k! formas de ordenar cada grupo. Acá tenés 6 ejemplos resueltos, con cada paso explicado y verificado.

Conceptos clave

Combinaciones

Elegir k de n sin importar el orden: se cuentan las variaciones y se divide por las k! formas de ordenar cada grupo.

C5,2​=2!5⋅4​=10

¿Qué fórmula de conteo uso?

Si importa el orden son variaciones (o permutaciones si se usan todos); si no importa, combinaciones. Si se pueden repetir, se usan las versiones “con repetición”.

Vn,k​=(n−k)!n!​,Cn,k​=k!(n−k)!n!​

Variaciones

Elegir k de n cuando importa el orden: se multiplican las opciones de cada lugar.

V5,2​=5⋅4=20

Permutaciones con repetición

Si hay letras iguales, intercambiarlas no forma una palabra nueva: por eso se divide por el factorial de cada repetición.

OSO:2!3!​=3

Factorial y permutaciones

n! cuenta las formas de ordenar n elementos distintos: n opciones para el primer lugar, n − 1 para el segundo, y así.

4!=4⋅3⋅2⋅1=24

Ojo con…

  • Preguntate primero si importa el orden: si importa son variaciones; si no, combinaciones.
  • n! crece muy rápido: simplificá los factoriales antes de multiplicar.
  • En una ronda se fija una persona: son (n − 1)! formas.
